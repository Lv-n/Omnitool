# Omnitool
  - Omnitool is a open source app, combining multiple tools into one. Its purpose is to be the ultimate tool

# What's in this app?
- Auto Clicker
  + Click interval range from 0.00001 seconds to 3600 seconds
  + Available mouse buttons: Left Click, Right Click
- Auto Typer
  + Minimum typing speed is 0
  + Trigger key can also be a combo like ctrl+m
  + To make multiple keys pressed at the same time, put them in a pair of square brackets, for example: "[abc]". But it won't work for [tab], [enter], [shift], [capslock] because it also has the functionality of pressing those keys instead of ordinary keyboard keys
- Text To Speech
  + Volume range from 0.0 to 1.0
  + Speed range from 50 to 300
-Cryptograph
  + Available encryption: Base64, XOR, Ceaser
  + Customizable encryption:
    - XOR
       + Customizable key (Key is required for encryption)
    - Caeser Cipher
      + Shift amount, default is 3
      + Alphabets, default is the English alphabet, you can change it to anything you want, Russian, Greek, Vietnamese, Spanish,... etc, anything you ever wanted

# Settings
  - Always On Top: Enable and disable app on top of other apps
  - Enable Sound: Enable and disable sound effect
  - Show In-app Console: Open a console for the app
  - Version: Show the current app version
